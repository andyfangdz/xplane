# X-Plane 12.4.4 beta 1 leads reviewed 2026-09-13/14

Reviewed the five pages of the [user-supplied discussion](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/), including subsequent corrections. Forum observations identify experiments; they do not establish a cause on this machine.

| Lead | Evidence and relevance |
| --- | --- |
| `--gfx_no_defragment` | Laminar lists this workaround for beta stutters/bad performance. Several forum users report improvement; some initially failed to pass the argument correctly. This study verifies the actual process arguments and tests both states. [Official notes](https://www.x-plane.com/kb/x-plane-12-4-4-release-notes/) |
| Texture cache | This disk cache reuses preprocessed textures. Laminar allows 0–10 GB and expects the greatest benefit with repeated regions and high-resolution scenery. It is not extra VRAM. The local default was 5 GB and the cache was full. This study compares 5 GB against 0; 10 GB is a separate capacity experiment. [Laminar explanation](https://www.x-plane.com/2026/09/whats-new-in-12-4-4-the-sdk-update/) |
| Cache disabled | Lotharxyz reports that 0 solved stutters; another user reports continued trouble with both cache 0 and the flag in an add-on-heavy installation. Neither is a measured comparison. [Page 4](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/?page=4), [page 5](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/?page=5) |
| Detached avionics windows | Daniel delapierre **retracted** his initial claim that rolling NVIDIA 616.92 back to 616.64 cured the problem. His later diagnosis was stuttering when avionics pop-ups became detached OS windows, regardless of driver or simulator version, with little average-FPS change. Other users prefer different drivers, but there is no common confirmed version to recommend. Local driver stays 616.92 throughout this study. [Page 5](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/?page=5) |
| SimHeaven vegetation/scenery paths | Users report missing assets; recreating the vegetation link helped one. Local inspection found the old free library points at a nonexistent `F:/X-Plane 12/Resources/default scenery/1200 forests`; both that library and the free America layers are disabled. Pro uses a different link to the current D: installation. The broken disabled link is a future cleanup item, not a cause of this stock-scenery experiment. [Page 2](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/?page=2), [page 3](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/?page=3) |
| Startup failures and Zink | Laminar lists a Zink assertion at startup and retry/ignore/disable-Zink workarounds. This is worth matching against a future startup failure log; it does not prove the cause of our earlier timeout/crash. Zink is held constant in this test. [Official notes](https://www.x-plane.com/kb/x-plane-12-4-4-release-notes/) |
| Tearing, night flicker, snow | The thread also covers tearing during pans, cloud-related night-light flicker that the flag did not fix, and ASXP/XA-Snow conflicts. Tearing calls for a separate display synchronization check. Snow overrides and nighttime lighting are not part of our clear daytime maneuver. [Page 4](https://forums.x-plane.org/forums/topic/351328-x-plane-1244-b1-is-out/?page=4), [official notes](https://www.x-plane.com/kb/x-plane-12-4-4-release-notes/) |

No forum-suggested DLL deletions, scenery moves, driver installs or texture conversions were applied. The cache is allowed to evolve normally during the comparison; this is not a cold-cache benchmark.
